# Swift Arm

Use this organization when you need the Arm architecture reference in Swift: its one package is [swift-arm-standard](https://github.com/swift-arm-ltd/swift-arm-standard), which follows its source document as literally as possible. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift Arm is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by Arm Limited.
